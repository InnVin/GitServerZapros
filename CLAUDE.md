# GitServerZapros — правила для Claude

## Режимы работы с ассистентами

Владелец выбирает режим, обычно префиксом в сообщении. Придерживайтесь режима, который он назвал.

| Режим | Модель | effort | Для чего |
|---|---|---|---|
| «Haiku Легкий» | claude-haiku-5-5 | — | Парсинг, считывание, сортировка, рутина, ассистент |
| «Opus Средний» | claude-opus-5-5 | Средний | Основная работа: код, логика, программист |
| «Opus Сверхвысокий» | claude-opus-5-5 | Сверхвысокий | Тимлид: задаёт направление, проверяет, ставит задачи, планы, контроль |

- Если режим не назван, работайте в «Opus Средний».
- Задачи для «Haiku Легкий» по возможности передавайте субагенту (Agent, model: haiku).
- В «Opus Сверхвысокий» не пишите код сами: ставьте задачи, проверяйте результат, давайте план.
